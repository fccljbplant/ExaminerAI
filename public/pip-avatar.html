Plug Pip into your AI

One function. That's the whole API you need.

Wherever your site currently receives the tutor's reply (REST, WebSocket or SSE), hand the text to Pip. He takes care of voice, lip-sync, captions and mood.

// in your existing chat handler…
Pip.think();                      // 🤔 hmm-face while waiting

const reply = await myAIBackend(message);

Pip.say(reply.text);              // 🗣 speaks + lip-syncs + captions
Pip.mood('happy');                // optional: happy|think|listen|sleep|idle
Pip.voice(false);                 // optional: mute the speech

In this demo the backend is mocked — replace mockAI() in the script with:

// example: your real endpoint
async function getAIReply(text){
  const r = await fetch('/api/tutor', {
    method: 'POST',
    headers: {'Content-Type':'application/json'},
    body: JSON.stringify({ message: text })
  });
  return (await r.json()).reply;
}
  • Pip.say(text) — speak a reply with animated mouth + word captions
  • Pip.think() — thinking face with bouncing dots
  • Pip.mood(name) — set an expression instantly
  • Pip.voice(bool) — toggle text-to-speech
  • Pip.wave() — little wave animation (great on page load)

Voice uses the browser's built-in SpeechSynthesis — no API key. Swap in ElevenLabs / your TTS provider later by replacing the speak() internals; the mouth animation is amplitude-driven, so any audio source works.
